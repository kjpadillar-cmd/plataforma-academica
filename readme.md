# Plataforma Académica Básica

## Descripción del Proyecto
Este repositorio forma parte del taller práctico de Control de Versiones para la asignatura. Consiste en la estructura inicial para una plataforma académica web donde se proyecta visualizar cursos, información de estudiantes y calificaciones. El objetivo principal de este desarrollo es poner en práctica el flujo de trabajo colaborativo con Git y GitHub (uso de ramas, commits, Pull Requests y merges).
